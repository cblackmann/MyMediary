# ✨ MyMediary

Aplicación web y PWA multi-usuario para llevar el registro, estadísticas, favoritos y watchlists de **Películas, Series, Música, Videojuegos y Lecturas**, sincronizada en tiempo real con **Supabase**.

## 🚀 Estructura del Proyecto

- [`index.html`](./index.html) / [`WebApp/`](./WebApp): Aplicación Web Progresiva (PWA) 100% independiente lista para alojar gratis en **GitHub Pages**, **Netlify** o **Vercel**.
- [`manifest.json`](./manifest.json), [`sw.js`](./sw.js), [`icon.svg`](./icon.svg): Archivos de configuración e ícono para instalar MyMediary como aplicación nativa en Android, iOS y PC.
- [`AppScript/`](./AppScript): Versión de respaldo compatible con Google Apps Script (incluye botón de migración en 1 clic desde Google Sheets a Supabase).
